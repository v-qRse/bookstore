## Пет-проект "Книжный магазин"
Web-приложение на Java, Spring Boot с шаблонизатором Thymeleaf. В качестве базы данных используется H2 с помощью Spring Data Jpa. 
Для авторизации используется Spring Security.


Так же на все поля настроена валидация с помощью Spting Validation.


Все зависимости можно посмотреть в [pom.xml](pom.xml).

---
Основная задача создания проекта - знакомство с основными компонентами Spring Boot и шаблонизатором Thymeleaf.
